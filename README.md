# PC資産管理

中小企業の情報システム部門向けの、PC台帳を管理するポートフォリオ作品です。Day 1 では台帳の登録・検索・編集・削除を実装しました。画面・メッセージは日本語です。

## 起動方法

Python 3.12 を使用します。外部ライブラリのインストールは不要です。

```bash
python3 app.py
```

ブラウザーで http://127.0.0.1:8000 を開きます。終了は Ctrl+C。ポートが使用中の場合は `python3 app.py --port 8001` で変更できます。コマンドを実行するディレクトリにかかわらず、DB・テンプレートは app.py のあるディレクトリを基準に読み書きします。

初回起動時に `data/assets.sqlite3` を作成し、架空のサンプル5件を投入します。通常の再起動や全資産削除後には再投入しません。バックアップはアプリ停止後にこのDBファイルをコピーしてください。全データを破棄して初期状態に戻す場合だけ、停止後にDBを削除して再起動します。

## 機能と操作

- 一覧：管理番号順に表示。管理番号・利用者・機種名を部分一致で検索（いずれかに一致）。空欄で全件、検索文字の `%`・`_` は文字そのものとして扱います。
- 新規登録：「＋ 新規登録」から入力して保存。管理番号は必須かつ一意です。状態の初期値は「在庫」です。
- 編集：一覧の「編集」から全項目と登録・更新日時を確認、変更して保存できます。
- 削除：一覧の「削除」から確認画面を開き、「削除する」で確定します。物理削除のため復元できません。
- 日付形式・保証期限と購入日の前後関係・入力長を検証し、エラー時は入力を保持します。

認証がないローカル利用向けの土台です。待受は `127.0.0.1` に限定しています。ログイン、CSV入出力、棚卸し、バーコードは未実装です。

## 設計

Flask がこの環境に存在しなかったため、Python 標準ライブラリの `http.server` と `sqlite3` を採用しました。ビルドや依存解決なしで起動でき、将来はDB処理・テンプレートを起点にFlask等へ移行できます。

画面は一覧（GET `/`）、登録（GET/POST `/assets/new`）、編集（GET/POST `/assets/{id}/edit`）、削除確認（GET/POST `/assets/{id}/delete`）です。更新系はPOSTのみとし、完了後は一覧へリダイレクトします。SQLはパラメーター化し、表示値はHTMLエスケープ、更新フォームには起動ごとのCSRFトークンを付けています。

### DBスキーマ

単一の `assets` テーブルで開始します。部署や利用者はDay 1では自由入力です。

| カラム | 型・制約 | 用途 |
| --- | --- | --- |
| id | INTEGER PRIMARY KEY | 画面URL用の内部ID |
| asset_number | TEXT NOT NULL UNIQUE、空白のみ不可 | 管理番号 |
| manufacturer / model | TEXT NOT NULL | メーカー / 機種名 |
| serial_number / os | TEXT NOT NULL | シリアル番号 / OS |
| purchase_date / warranty_date | TEXT NOT NULL | 購入日 / 保証期限、YYYY-MM-DD |
| user_name / department / location | TEXT NOT NULL | 利用者 / 部署 / 設置場所 |
| status | TEXT NOT NULL、CHECK制約 | 使用中 / 在庫 / 修理中 / 貸出中 / 廃棄 |
| notes | TEXT NOT NULL | 備考 |
| created_at / updated_at | TEXT NOT NULL、自動設定 | UTCの登録 / 更新日時 |

任意項目の未入力は空文字で統一します。管理番号以外の通常項目は最大200文字、備考は2000文字です。登録日時は保持し、更新時に更新日時のみ変更します。小規模台帳を想定し、部分一致検索は全件走査としています。ページ分割、同時編集の競合検出、変更履歴は今後の課題です。

## 動作確認

通常環境では、実際のローカルHTTPサーバーと一時DBでテストできます。

```bash
python3 -m unittest discover -s tests -v
```

ソケット利用が禁止された環境では、同じHTTPハンドラーにメモリ内のHTTPリクエストを渡す代替テストを実行できます。

```bash
ASSET_TEST_OFFLINE=1 python3 -m unittest discover -s tests -v
```

2026-11-10 / Python 3.12.3：代替テストは3件成功。検索3項目、新規登録、編集、削除確認と確定、DB保持、初回のみの5件投入、全件削除後の再投入防止、入力エラー、重複管理番号、HTMLエスケープ、CSRF拒否、404、CSS取得を確認しました。本環境ではソケット作成が `PermissionError: [Errno 1] Operation not permitted` となるため、通常のサーバー起動とブラウザーでの操作・見た目は未確認です。
